# PERSONA

Платформа подбора бизнес-ассистентов. React + TypeScript + Vite + Tailwind CSS.

Единое приложение с боковой навигацией и двумя ролями — **Ассистент** и **Работодатель**.

## Разделы

**Ассистент:** Сервисы и инструменты · Дашборд · Моё приложение · База знаний · Анкета в базу · Тест личности OCA · Тест Адизеса PAEI · Бизнес-совместимость

**Работодатель:** Дашборд · Разместить вакансию · Тарифы · Партнёрская программа · Бизнес-совместимость · База знаний

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## Сборка

```bash
npm run build      # production-сборка в dist/
npm run preview    # локальный просмотр собранной версии
```

## Деплой

### Vercel

1. Запушьте репозиторий на GitHub.
2. На [vercel.com](https://vercel.com) → **Add New Project** → импортируйте репозиторий.
3. Vercel сам определит Vite (настройки уже заданы в `vercel.json`). Нажмите **Deploy**.

Каждый `git push` в основную ветку автоматически публикует новую версию.

### GitHub Pages

Сборка кладётся в `dist/`. Можно опубликовать через GitHub Actions или вручную залить `dist/`.
