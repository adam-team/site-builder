# Установка окружения

Это делает агент, ученице ничего ставить не нужно. Одна команда:

```bash
bash scripts/bootstrap.sh
```

Что проверяет скрипт:

1. **Python 3**: на нём сборка сайта, структура и каталог. Работает без пакетов.
2. **Google Chrome**: в нём открываются конструктор, галерея и проверка сайта.
3. **Node.js 20+**: нужен только для шаблонов React и Next, для записи видео-превью и для выкладки на Vercel (`npx vercel`).
   Если его нет: на Mac `brew install node`, на Windows `winget install OpenJS.NodeJS.LTS`.
4. **ffmpeg**: только для записи новых видео-превью (`brew install ffmpeg`). Ученице он не нужен: видео уже лежат в `gallery/media/`.
5. Собирает данные для конструктора (`structure/presets.js`) и галереи (`gallery/data.js`).
6. Ставит хук-сторож секретов перед коммитом.

Когда скрипт готов, сразу переходи к опросу: `docs/agent-contract/WORKFLOW.md`, этап 1.
