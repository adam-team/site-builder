7 этапов с агентом

этапчто происходит
1 темачем занимаетесь, кто посетитель, одно главное действие
2 структураесть своя — раскладываем по блокам, нет — собираем в конструкторе
3 дизайнДизайн-тека: 89 видео, выбираете до трёх номеров
4 текстыпо блокам сверху вниз, черновики агента только с вашим «да»
5 сборкаагент собирает сайт по трём файлам: структура, дизайн, тексты
6 проверкаскриншоты компьютера и телефона, поиск заглушек
7 запускVercel, GitHub Pages или архив

На каждом этапе агент задаёт один вопрос с вариантами и ждёт ответа.

Первый вопрос: есть структура?

да, есть план
Присылаете текст, файл или ссылку Агент раскладывает его по 15 блокам, показывает список «Так?» и записывает STRUCTURE.md.
нет плана
Собираем вместе в конструкторе Выбираете тему, размер и блоки галочками. Справа сразу видно сайт на телефоне.
чат с агентом

«У тебя уже есть структура сайта: план блоков, документ или пример? 1) да, пришлю 2) нет, соберём в конструкторе 3) предложи сама»

Установка одним сообщением

Claude Code · пустая папка
Склонируй репозиторий https://github.com/adam-team/site-builder
в папку site-builder, подготовь окружение по SETUP.md
и сразу начни опрос по docs/agent-contract/WORKFLOW.md.
Я хочу сайт с красивым дизайном. Спрашивай по одному
вопросу, с вариантами ответа.

Репозиторий приватный: сначала получите доступ у Куралай. Python, Node и Chrome агент проверит и поставит сам.
