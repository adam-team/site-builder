# Старт за 10 минут

Это для ученицы, которая хочет свой сайт с красивым дизайном. Программировать не нужно: всё делает Claude Code, а ты отвечаешь на вопросы и выбираешь.

## 1. Что нужно

- Компьютер (Mac или Windows) и Google Chrome.
- Claude Code (приложение или терминал) с подпиской. Лучше всего самая новая Opus с усилием high.
- Аккаунт GitHub (бесплатный). На этапе запуска понадобится Vercel, он тоже бесплатный.

## 2. Установка одним сообщением

Открой Claude Code в пустой папке и отправь:

```text
Склонируй репозиторий https://github.com/adam-team/site-builder в папку site-builder,
подготовь окружение по SETUP.md и сразу начни опрос по docs/agent-contract/WORKFLOW.md.
Я хочу сайт с красивым дизайном. Спрашивай по одному вопросу, с вариантами ответа.
```

Репозиторий приватный: сначала Куралай даёт тебе доступ на GitHub.

## 3. Что будет дальше

1. **Тема**: чем занимаешься и что должен сделать посетитель.
2. **Структура**: агент спросит, есть ли у тебя план сайта. Нет? Откроется **конструктор**: выбираешь тему, размер и блоки, а справа сразу видно сайт на телефоне.
3. **Дизайн**: откроется **Дизайн-тека** с 89 видео, как на YouTube. Наведи мышку, чтобы посмотреть превью, нажми, чтобы открыть. Выбери до трёх и нажми «Скопировать для агента».
4. **Тексты**: агент спрашивает по каждому блоку. Можно отвечать голосом.
5. **Сборка и проверка**: агент присылает скриншоты для компьютера и телефона, ты говоришь, что поправить.
6. **Запуск**: сайт появляется в интернете по ссылке.

## 4. Как отвечать

- Цифрой варианта: «2».
- Или своими словами, агент переспросит, если непонятно.
- «Не знаю» тоже нормальный ответ: агент предложит черновик и спросит, подходит ли.
- Цены, отзывы, телефоны и цифры называешь только ты, агент их не выдумывает.

## 5. Если агент сбился

```text
Остановись. Прочитай CLAUDE.md и docs/agent-contract/WORKFLOW.md.
Скажи, на каком мы этапе и какие файлы в projects/ уже заполнены. Продолжай с этого этапа по одному вопросу.
```

## 6. Сколько это занимает

На тему и структуру уходит 15-20 минут, на дизайн 10-20, на тексты 20-40. Сборка, проверка и запуск занимают около часа.
Можно остановиться в любой момент: агент продолжит с того места, где остановились, по файлам в `projects/<имя>/`.
