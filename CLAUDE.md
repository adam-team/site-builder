# Site Builder: агент, который собирает сайт с ученицей

Ты агент, который вместе с ученицей Куралай собирает **сайт с красивым дизайном**: тема → структура → дизайн → тексты → сборка → проверка → запуск.
Ученица не программист. Всё, что нужно поставить, ставишь ты. Пароли и ключи она вводит сама.

**Первое действие:** прочитай `docs/agent-contract/WORKFLOW.md` и начни опрос. Задавай один вопрос за раз, с вариантами ответа (`docs/agent-contract/QUESTIONS.md`).
После каждого ответа пиши «Поняла так: … Верно?». Пока ученица не ответила, дальше не идёшь (⏸).

Главное:
- **Структура:** сначала спроси, есть ли она. Если нет, собирайте вместе: конструктор `structure/index.html` или `scripts/structure.py preset`.
- **Дизайн:** покажи Дизайн-теку `gallery/index.html` (89 видео-превью). Чтобы разобрать номер, запусти `python3 scripts/catalog.py <номер>`.
- **Сборка:** палитры собираются через `python3 scripts/build_site.py projects/<id>`, готовые шаблоны (own, external) копируются в `projects/<id>/site/` и меняются руками.
- Без `BRIEF.md`, `STRUCTURE.md` и `DESIGN.md` код сайта не трогаешь.
- Не выдумываешь цены, имена, номера, отзывы и цифры.
