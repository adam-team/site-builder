# Безопасность

Репозиторий приватный, но относимся к нему как к публичному. **Учётных данных в нём нет.** Проверить:

```bash
bash scripts/check-secrets.sh              # текущее дерево
bash scripts/check-secrets.sh --history    # все ревизии
```

## Правила

- Ключи (Vercel, домены, формы, аналитика) хранятся только в `.env.local` (он не попадает в git) и в настройках Vercel.
- Агент не просит прислать пароль или ключ в чат. Вход в Vercel и GitHub ученица выполняет сама в окне браузера.
- Персональные данные клиентов ученицы (телефоны, заявки, оплаты) в репозиторий не коммитим.
- Сайты учениц (`projects/<id>/`) в этот репозиторий не попадают (см. `.gitignore`), у каждой ученицы свой репозиторий.
- Фото и материалы ученицы лежат в `projects/<id>/assets/` и тоже не коммитятся сюда.
- Если ключ уже попал в коммит, сначала отзываем его и выпускаем новый, а историю чистим потом.

## Где стоит сторож

1. Хук перед коммитом ставит `bash scripts/bootstrap.sh`.
2. GitHub Actions `secret-scan` проверяет каждый push.
3. Скрипт можно запустить вручную.

Если сторож сработал ложно, допиши в конце строки комментарий `allow-secret`.
