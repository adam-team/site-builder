# Дизайн

1. **Выбирай по настроению темы, а не по любимому цвету.** Психологу подходят спокойные светлые тона (Аврора, Мягкий коралл), IT подходят тёмные и стекло (Liquid Glass, Obsidian),
   премиуму нужны засечки и много воздуха (Люкс, Кино-нуар), детям и сервисам подходит мягкая глина.
2. **Один акцентный цвет для кнопок.** Если всё яркое, ничего не заметно.
3. **Контраст текста:** серый текст на сером фоне не читается на телефоне на солнце.
4. **Два шрифта максимум:** один для заголовков, один для текста. Для казахского языка проверь ә ғ қ ң ө ұ ү һ і.
5. **Анимации мягкие:** блоки появляются при прокрутке, 3D-наклон только на карточках. Анимация, которая мешает читать, вредит продажам.
6. **Фото эксперта живое и тёплое.** Без фото оставь цветные абстракции шаблона, а не стоковые фото.
7. **Готовый шаблон с GitHub** хорош, когда структура почти совпадает. Если блоки сильно другие, быстрее взять палитру под наш шаблон.
8. Выбираешь из трёх? Собери все три на своей структуре и сравни на телефоне. Решай глазами, а не по обложке.
