Ты начинаешь или продолжаешь сборку сайта. Порядок жёсткий, шаги не пропускать.

1. Прочитай `CLAUDE.md`, `CONTEXT.md` и `docs/agent-contract/WORKFLOW.md`.
2. Если есть `projects/<id>/` с заполненными файлами, скажи, на каком этапе вы остановились, и продолжай с него.
   Если нет: `bash scripts/bootstrap.sh`, затем спроси имя проекта и выполни `bash scripts/new-project.sh <id>`.
3. **Этап 1, тема ⏸.** Блок A из `QUESTIONS.md`, по одному вопросу → `BRIEF.md`.
4. **Этап 2, структура ⏸.** Сначала спроси, есть ли структура. Если есть, разложи её по блокам. Если нет, открой `structure/index.html`
   или проведи её в чате через `python3 scripts/structure.py preset <тема>`. Затем выполни `python3 scripts/structure.py write projects/<id> …`.
5. **Этап 3, дизайн ⏸.** Открой `gallery/index.html`. Если ученица назвала настроение, предложи 3 номера (`scripts/catalog.py find`).
   По выбранным номерам запусти `scripts/catalog.py <номер>`, при необходимости собери образцы на её структуре → `DESIGN.md`, `design` в `site.json`.
6. **Этап 4, тексты ⏸.** По блокам сверху вниз → `CONTENT.md`, `content` в `site.json`.
7. **Этап 5, сборка.** Только когда готовы `BRIEF.md`, `STRUCTURE.md` и `DESIGN.md`.
8. **Этап 6, проверка ⏸.** Скриншоты для компьютера и телефона, `check-site.sh`, `check-secrets.sh`.
9. **Этап 7, запуск ⏸.** Сначала спроси подтверждение.

После каждого ответа пиши: «Поняла так: … Верно?». Не выдумывай цены, номера, имена и отзывы.
