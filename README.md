# Site Builder: обучалка «Сайт с красивым дизайном»

Репозиторий для **Claude Code** и **Codex**. Ученица отвечает на вопросы, а агент вместе с ней собирает структуру, предлагает
дизайны в виде видео (как на YouTube), пишет тексты и выкладывает готовый сайт.

> **Агенту:** подготовь окружение по [`SETUP.md`](SETUP.md) и сразу начни опрос по
> [`docs/agent-contract/WORKFLOW.md`](docs/agent-contract/WORKFLOW.md). Задавай один вопрос за раз, с вариантами ответа.
> Если ты новичок, начни с [`START.md`](START.md): там старт за 10 минут.

## Как это работает

1. **Тема и цель ⏸**: чем занимаешься, кто посетитель, какое одно действие он должен сделать.
2. **Структура ⏸**: агент спрашивает, есть ли у тебя структура. Если есть, раскладывает её по блокам. Если нет, вы собираете её вместе в
   **конструкторе** `structure/index.html`: 10 тем, 15 блоков, превью на телефоне.
3. **Дизайн ⏸**: в **Дизайн-теке** `gallery/index.html` 89 дизайнов в виде видео-превью. Выбираешь до трёх, агент показывает образцы на твоей структуре.
4. **Тексты ⏸**: по блокам сверху вниз. Цены, цифры и отзывы называешь только ты.
5. **Сборка**: палитры собираются шаблоном `template/`, а готовые шаблоны агент копирует и переделывает.
6. **Проверка ⏸**: скриншоты для компьютера и телефона, поиск заглушек, сторож секретов.
7. **Запуск ⏸**: Vercel, GitHub Pages или архив.

⏸ значит, что агент задал вопрос и ждёт ответа. Каждый этап закрывается файлом в `projects/<id>/`.

## 89 дизайнов

| Номера | Что | Тип |
|---|---|---|
| 1-8 | **Мои дизайны**: BOSS VISION (10 вариантов, v2, первые наброски, экраны приложения), главная эксперта, лендинг интенсива, варианты теста телесного терапевта, PERSONA | готовый код в `designs/own/` |
| 9-40 | **Дизайны платформ**: 32 палитры из Platform Builder (финансовый консультант, PERSONA, брендбук Куралай, концепты подбора персонала, базовые) | палитра + шаблон `template/` |
| 41-50 | **Тренды 2026**: Bento, Liquid Glass, необрутализм, люкс с засечками, аврора-градиент, швейцарский журнал, мягкая глина, кино-нуар, степь-орнамент, чистая мята | палитра + шаблон |
| 51-89 | **GitHub-шаблоны**: 21 лендинг awesome-landing-pages, Start Bootstrap (6), Creative Tim (3), Landwind, Tailwind Toolbox, shadcn, Next SaaS, React Landing, Next.js Starter, Tailblocks, Cruip (2) | код в `designs/external/` |

Полная таблица: [`catalog/CATALOG.md`](catalog/CATALOG.md). Источник данных: `catalog/designs.json`.

У каждого дизайна есть видео-превью (`gallery/media/<номер>.mp4`), обложка и живой сайт. У шаблона для палитр 4 вида первого экрана,
6 видов карточек (мягкие, контур, стекло, плоские, брутализм, глина) и 4 анимации (подъём, проявление, приближение, 3D-наклон).

## Что внутри

| Папка | Что |
|---|---|
| `CLAUDE.md`, `AGENTS.md` | входы для Claude Code и Codex |
| `START.md`, `SETUP.md`, `CONTEXT.md` | старт, установка, карта «что где» |
| `docs/agent-contract/` | `WORKFLOW.md` (этапы), `QUESTIONS.md` (вопросы с вариантами) |
| `structure/` | конструктор структуры (`index.html`) и темы с блоками (`presets.json`) |
| `gallery/` | Дизайн-тека: страница выбора как на YouTube, видео, обложки, живые образцы |
| `catalog/` | все дизайны (`designs.json`, `CATALOG.md`) и шрифты (`fonts.json`) |
| `designs/own/` | дизайны Куралай: код |
| `designs/external/` | шаблоны с GitHub: код и лицензии |
| `template/` | шаблон сайта для палитр (CSS + генератор `scripts/build_site.py`) |
| `knowledge/` | правила: структура, дизайн, тексты, запуск |
| `projects/_template/` | заготовки файлов этапов |
| `scripts/` | новый проект, сборка, структура, каталог, проверки |
| `tools/` | запись видео-превью (puppeteer + ffmpeg) |

## Команды

```bash
bash scripts/new-project.sh anna-psy                    # новый проект
open structure/index.html                               # конструктор структуры
open gallery/index.html                                 # Дизайн-тека
python3 scripts/catalog.py find тёмный                  # поиск дизайна
python3 scripts/build_site.py projects/anna-psy         # собрать сайт
bash scripts/check-site.sh projects/anna-psy/site       # проверить сайт
cd tools && npm install && node record-previews.mjs     # дописать видео новым дизайнам
python3 scripts/build_gallery.py                        # обновить галерею
```

Добавить свой дизайн: допиши запись в `catalog/designs.json` (для готового кода положи его в `designs/own/<имя>/`), затем
`node tools/record-previews.mjs <номер>` и `python3 scripts/build_gallery.py`.
